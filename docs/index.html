How to install

1

Download the DMG above

Pick Apple Silicon if your Mac has an M1, M2, or M3 chip. Pick Intel if it's an older Intel Mac. Not sure? Click the menu → About This Mac and look for "Chip" or "Processor".

2

Open the DMG and drag to Applications

Double-click the downloaded .dmg file, then drag Userscript Browser into the Applications folder.

3

Remove the macOS quarantine flag

macOS blocks apps that aren't signed with a $99/year Apple certificate. Run this once in Terminal to allow it:

xattr -rd com.apple.quarantine "/Applications/Userscript Browser.app"
How to open Terminal: Press ⌘ Space, type Terminal, press Enter. Paste the command above and press Enter.
Alternatively, right-click (or Control-click) the app in Finder and choose Open, then click Open in the dialog. macOS will remember your choice.
4

Open the app

Launch Userscript Browser from your Applications folder or Spotlight (⌘ Space). That's it.

Install via Terminal (one command)

Paste this into Terminal — it detects your chip, downloads the right build, installs it, and removes the quarantine flag automatically.

curl -fsSL https://raw.githubusercontent.com/KUKARAF/userscript-electron/main/.tools/install.sh | bash

Updates

✓

In-app updates (automatic)

The app checks for a new release a few seconds after launch. When one is found, a banner appears at the top of the window.

Update available banner → Click Download → Click Restart Now → Done ✓
macOS note: because the app is unsigned, a Terminal window will briefly open to perform the install. You'll see it extract and replace the app, then Userscript Browser relaunches automatically. You can close the Terminal window afterwards.
↺

Manual update via Terminal

Re-running the install command updates to the latest version, or does nothing if you're already up to date.

curl -fsSL https://raw.githubusercontent.com/KUKARAF/userscript-electron/main/.tools/install.sh | bash
